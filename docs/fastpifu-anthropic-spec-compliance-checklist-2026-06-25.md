**Key Spec Requirements (agentskills.io/specification)**

Name: 1–64 chars, lowercase alphanumeric + hyphens, no leading/trailing/consecutive hyphens, must match directory name.

Description: 1–1,024 chars. Must describe WHAT the skill does and WHEN to use it. Include keywords for agent matching.

No README.md: only SKILL.md permitted at skill root. References and scripts go in subdirectories.

No internet dependency: all reference material must be bundled inside the skill folder.

SKILL.md body: under 500 lines / 5,000 tokens recommended. Move detail to references/ for progressive disclosure.

Progressive disclosure: metadata (~100 tokens, always loaded) → SKILL.md body (on trigger) → references/ files (on demand).

File references: use relative paths from skill root. Keep references one level deep — avoid deeply nested chains.
