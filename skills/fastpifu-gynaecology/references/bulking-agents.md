# Bulking agents (urethral bulking for stress urinary incontinence)

## Scope

Patients treated with urethral bulking agents for stress urinary incontinence, followed up after
the procedure. Uncomplicated incontinence managed conservatively is covered separately in
`urinary-incontinence.md`.

## PIFU — suitable for patient-initiated follow-up

- Criterion: PIFU suitable following successful treatment.
  Supported when: letter confirms symptomatic improvement after the bulking agent procedure.

## RETAIN_FOLLOW_UP — timed specialist follow-up still needed

- Inadequate response or complication following the procedure, requiring specialist review and
  consideration of a repeat procedure or escalation to surgery.

## DISCHARGE — no ongoing specialist follow-up needed

- Symptoms resolved with no ongoing need — return to primary care/continence service, with a
  documented route back if symptoms recur.

## Data that must be present to assess

| Required data point | Why it matters |
|---|---|
| Procedure date | Confirms treatment given |
| Symptom response (e.g. validated incontinence questionnaire) | Confirms improvement |
| Any complications | Identifies need for retained follow-up |

## Surveillance / review interval

PIFU 6 months; trigger for return appointment is persisting symptoms; remote appointment type.
